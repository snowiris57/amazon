# 欲しいもの整理（Wishlist Organizer）

Amazonの「欲しいものリスト」は件数が増えると一覧が見づらくなります。
このアプリはリストのアイテムを**カテゴリごとに自動分類して整理**し、
さらに**価格の買い時**を判断しやすくするための、ブラウザだけで動く軽量ツールです。

> インストール不要・依存ライブラリなし・データは端末内（localStorage）に保存され、外部に送信しません。

---

## できること

- **自動カテゴリ分類** — 商品タイトルから「家電・ガジェット」「本・書籍」「ファッション」など15カテゴリに自動振り分け
- **カテゴリ別／一覧の表示切替**、検索・並べ替え（価格・優先度・追加順・名前）・絞り込み
- **優先度（高・中・低）と購入済みチェック**、未購入合計金額などの統計
- **まとめて取り込み** — 欲しいものリストからコピーしたテキストを貼り付けると、価格を抽出しつつ自動分類
- **価格の買い時判定** — 記録した価格履歴から最安値と現在値を比べ、`買い時！` / `値下がり待ち` などを表示（スパークライン付き）
- **Keepa / camelcamelcamel 連携** — Amazon URL から ASIN を抽出し、本物の価格推移グラフにワンクリックで移動
- **JSON / CSV での書き出し・取り込み**（バックアップや表計算での利用に）

## 使い方

1. `index.html` をブラウザで開く（ダブルクリックでOK。サーバー不要）
2. 「サンプルを読み込む」で動作を確認、または
3. 「＋ アイテムを追加」で1件ずつ登録、あるいは「取り込み」でまとめて追加

### まとめて取り込みのコツ

Amazonの欲しいものリスト画面で商品名や価格を選択してコピーし、取り込みの「貼り付け」欄に貼り付けます。
1行1商品として解釈し、`¥1,980` や `1,980円` のような価格を自動抽出、タイトルからカテゴリを判定します。
URL（`https://www.amazon.co.jp/dp/XXXXXXXXXX`）が含まれていれば、Keepa等の価格推移リンクも有効になります。

## 価格監視について

正確な価格推移・最安値の追跡は、実データを持つ既存サービスに任せる設計です。

- **[Keepa](https://keepa.com/)** — 各アイテムの `📈 Keepa` から該当商品の価格グラフへ
- **[camelcamelcamel](https://jp.camelcamelcamel.com/)** — `🐫 Camel` から同様に

アプリ内の価格履歴は、取り込み・編集・「💰 価格」からの手動記録で蓄積される**補助的な目安**です。
定期的に最新価格を取り込むほど、買い時判定の精度が上がります。

## ファイル構成

```
index.html            画面の構造
assets/styles.css      スタイル（ライト/ダーク対応）
assets/categories.js   カテゴリ定義と自動分類ロジック
assets/app.js          アプリ本体（状態管理・描画・取り込み/書き出し）
```

## カテゴリを増やす・調整する

`assets/categories.js` の `CATEGORIES` 配列を編集します。
各カテゴリに `keywords` を足すと、その語を含むタイトルが自動的にそのカテゴリへ分類されます。

## 制限事項

- Amazonからの価格・商品情報の**自動取得は行いません**（ブラウザのCORS制約とAmazonの利用規約のため）。
  取り込みは手動の貼り付け／JSON・CSVで行います。
- データはブラウザごと・端末ごとに保存されます。別端末へ移すには JSON で書き出して取り込んでください。
